# GWDC 제출 준비 체크리스트

**프로젝트:** TRON Treasury Copilot — 예정 지출과 비상금을 먼저 확보하고, 남는 USDT의 순수익·회수 조건을 비교하는 사용자 서명형 자금 계획 도구.

**대상:** GWDC 2026 Korea / TRON Challenge B, AI Asset Allocation & Yield Planning Assistant. 요건의 출처는 [공식 TRON Challenge Brief](https://drive.google.com/file/d/1HXLhu1_vCoMD5aN3APEYEjDrh9oVCj7g/view)와 [행사 안내](https://luma.com/be2le0l0)입니다. 자세한 대응표는 [HACKATHON.md](HACKATHON.md).

체크표의 “준비됨”은 기능·자료의 존재를 뜻합니다. 실자금 성공, 공개 배포, 제출 완료를 뜻하지 않습니다. 실제 검증 이력은 [RESUME.md](RESUME.md)를 우선합니다.

## 제출 전 마무리

- [ ] 주최 측 최종 제출 폼, 팀 정보, 저장소 공개 범위, 영상 길이·파일 규격, 발표자료 양식을 확인합니다. 이 저장소의 3분 대본은 자체 준비안입니다.
- [ ] 메인넷 실거래 필수 여부와 테스트넷 허용 범위를 확인합니다. 명시적 가상 회고 허용을 전체 실행 요건 면제로 해석하지 않습니다.
- [ ] 확인된 배포 주소 또는 로컬 실행법, Git 저장소 링크와 재현 가능한 commit을 제출물에 기입합니다. 없는 URL을 임시로 완성된 서비스처럼 적지 않습니다.
- [ ] `npm run typecheck`, `npm test`, `npm run build`, `npm run smoke`의 최종 결과를 저장합니다. 추가 변경 후의 결과가 문서와 일치해야 합니다.
- [ ] GitHub Actions를 처음 연결했다면 CI와 Docker startup 검사의 실제 결과를 확인합니다. 현재 워크플로 파일만 준비된 상태와 구분합니다.
- [ ] [배포 실행서](DEPLOYMENT.md)에 따라 이 프로젝트 전용 서비스의 공개 링크를 확인합니다. 기존 서비스의 변수·DB·도메인을 변경하지 않습니다.
- [ ] AI가 필요한 제출에서는 전용 키·모델로 실제 해석을 검증합니다. 공유 링크에 유료 AI를 열기 전에 접근 제한/서버 예산을 준비하거나 공개 버전은 수동 모드로 유지합니다.
- [ ] 사용자 지갑 서명이 필요한 실제 거래를 수행했다면 금액·시간·txID·확정/반환 코드·회수 결과를 별도 비공개 검증 기록에 남깁니다. 실패나 미확정을 성공으로 바꾸지 않습니다.
- [ ] [3분 대본](DEMO-SCRIPT.md)으로 녹화하고 DEMO, LIVE, 가상 회고, 실제 거래의 구분이 화면과 말에서 일치하는지 확인합니다.
- [ ] 영상과 공개 Git 변경 목록에 개인키·API 키·`.env`·실제 지갑 내보내기·다른 프로젝트의 파일이 없는지 확인합니다.
- [ ] 제출 폼에 링크·설명·파일을 넣고 제출 성공 기록을 보존합니다. 코드 작성이나 Git push만으로 제출 완료라고 표시하지 않습니다.

## 제품 소개 초안

> TRON Treasury Copilot은 사용자의 예정 지출과 비상금을 먼저 확보한 뒤 남는 USDT의 운용안을 비교합니다. 자연어 조건을 사용자가 확인하고, 별도 계산 엔진이 기본 이자·인센티브·왕복 비용·현재 유동성·노출 한도를 반영합니다. 보유가 더 적합하면 그대로 보유하도록 제안하며, 거래는 사용자가 전문을 확인한 후 자신의 지갑에서 서명합니다. 원계획과 가정을 저장해 변화와 가상 회고를 비교하고, 검증되지 않은 자산 경로는 추천·실행에서 제외합니다.

영문 한 문장:

> Plan around when you need your money, then compare yield after costs and liquidity constraints.

미구현 항목이나 미검증 실거래를 소개문에 추가하지 않습니다. “수익 보장”, “AI 완전 자율 운용”, “모든 TRON DeFi 지원”, “공식 파트너십”을 주장하지 않습니다.
