# 테스트 화면

- `desktop.png`, `mobile.png`: Playwright에서 생성한 기본 데모 계획 화면.
- `monitoring-mobile.png`: Playwright의 **모의 API·모의 지갑**을 사용한 관측 화면. 화면의 LIVE 표시는 실시간 UI 경로의 테스트이며, 그림 속 잔고·금리·주소를 실제 사용자 자산이나 최신 시장 수치로 소개하면 안 됩니다. 테스트 주소는 공개 토큰 계약을 식별자로 사용한 가짜 지갑입니다.

이미지는 UI 검증 자료입니다. 실제 거래·실현 수익·서비스 공개 배포의 증거가 아닙니다. 개인 Chrome 프로필이나 개인 지갑 키를 사용하지 않았습니다.
