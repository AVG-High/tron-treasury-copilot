## 핵심 결정

- 예정 지출과 비상금은 전액 예약하고 잔여 자금의 운용 기간을 따로 받습니다.
- 스트레스에서 결과가 반드시 바뀌도록 만들지 않습니다. 예약금으로 충당되면 유지가 정답입니다.
- 공식 요건 때문에 SUN 대신 USDD를 우선 연결했습니다. 출처·계약을 확인할 수 없는 경로는 시연을 위해 억지로 활성화하지 않습니다.
- 데이터 조회, 결정론적 계산, 사용자 서명 실행을 분리했습니다.
- 비용 가정은 예치 준비 시 실제 지갑 비용 견적으로 둔갑하지 않습니다.

## 데모 진행안

1. 10,000 USDT 예시: 3,000/7일 + 1,000/30일 + 비상금 500 → 4,500 예약.
2. 30일 잔여 자금 운용에서 보유·순수익 우선·유동성 우선 비교.
3. 기존 지출을 내일로 옮겨도 배분 유지, 새 지출 3,000 추가 시 운용 규모 축소.
4. 실시간 모드에서 출처와 현재 JustLend USDT 데이터 확인. USDD 제외 근거 공개.
5. 사용자 지갑이 준비된 경우만 정확한 승인·예치·회수 흐름을 보여줍니다. 미수행 거래를 실행했다고 표현하지 않습니다.
6. 계획 저장 후 가상 회고에서 금리 50%·비용 150% 결과를 원래 계획과 비교합니다. 반드시 가상 결과라고 표시합니다.
