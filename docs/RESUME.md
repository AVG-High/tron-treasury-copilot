- 지갑 잔고·현재 포지션 조회. USDT 정확한 승인·0 초기화·예치·회수 미서명 거래 생성.
- TronLink 사용자 서명·전송. 메인넷/코드 지문/직렬화/금액/비용/반환 코드 검증. 서버 서명 없음.

- 거래 준비 시 고유 계획 스냅샷 ID 보존, 거래 기록과 연결.
- 계산/거래 준비 중 변경된 입력에 과거 응답을 적용하지 않는 revision 검사.
- 계획 저장·조건 복원·JSON 내보내기, 가상 회고의 원래 예상/가상 결과/차이 비교.
- API 요청 검증·Origin/Host 제한·서버 전용 키·요청 한도·민감한 요청 로그 금지.
- 독립 Docker 배포 준비. 현재 서버는 로컬 루프백만 사용.
- 실시간 원계획의 1/5/15분 관측, 기본 OFF, 브라우저 숨김/거래 작업 시 일시 정지, 실패 백오프·3회 중지, 지연 응답 폐기.

## 아직 확인하거나 추가해야 하는 것

1. **AI 실제 연동**: 비어 있는 전용 `.env` 양식을 권한 600으로 준비했습니다(Git 제외). `OPENAI_API_KEY`, 사용 가능한 `OPENAI_MODEL`을 사용자가 넣어야 합니다. 키를 추가하거나 유료 모델 호출을 하지 않았습니다.
2. **사용자 지갑 왕복 검증**: TronLink 계정·필요한 USDT/TRX를 사용자가 준비한 뒤 소액 승인→예치→회수를 직접 확인·서명해야 합니다. 코드는 구현했지만 실자금 성공을 주장하지 않습니다.
3. **USDD 왕복 경로 구현**: 토큰 식별 문제는 해결했습니다. Join/PSM의 정확한 역할·승인 대상은 문서에 있지만 실시간 양방향 한도·Vat 상태·거래 시뮬레이션·전환/예치/회수/중간 실패 복구는 미구현입니다. 현재 토글을 한 번 읽은 것을 실행 허가로 사용하지 않습니다.
4. **실제 개인 수익 원장(이번 제출의 필수 추가 개발 아님)**: 공식 Challenge Brief 2페이지는 명시적 가상 회고를 허용합니다. 현재는 실제 관측 기록·평가액 변화와 가상 회고이며 완전한 개인 실현 수익 원장은 없습니다.
5. **제출/배포**: 설정·소개문·소스 ZIP·짧은 무음 데모를 준비했습니다. 제출 폼·마감·공개 저장소/배포 진행 여부를 질문했으며 미확인입니다. 외부 저장소 생성·공개 배포·제출은 수행하지 않았습니다. 로컬 URL은 외부 심사위원이 접속할 수 없습니다.
