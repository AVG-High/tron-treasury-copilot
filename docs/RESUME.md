## 완료한 범위

- 한국어 반응형 화면: 자금 계획, 상품·데이터, 포지션·회고.
- 예정 지출 전액 예약, 비상금, 잔여 자금의 별도 기간, 합산 프로토콜/USDD 상한.
- Decimal/BigInt 계산, 고정 비용을 포함한 완전 자금 조달, 보유 기준안과 최대 2개 양의 순수익 대안.
- 기존 지출 조기 도래 / 추가 지출 / 운용 기간 단축 시나리오.
- 기본 이자·인센티브·비용 분리, 손익분기, 탈락 사유, 데이터 출처·시각.
- JustLend와 USDD 공식 실시간 API 조회. USDD 불일치 경로는 비활성.
- 선택적 OpenAI Responses 구조화 조건 추출. 환경 미설정 시 수동 모드.
- 지갑 잔고·현재 포지션 조회. USDT 정확한 승인·0 초기화·예치·회수 미서명 거래 생성.
- TronLink 사용자 서명·전송. 메인넷/코드 지문/직렬화/금액/비용/반환 코드 검증. 서버 서명 없음.
- 만료·계정 교체·변조·기록 저장 실패 시 전송 차단. 불확실한 전송은 자동 재전송하지 않음.
- 거래 준비 시 고유 계획 스냅샷 ID 보존, 거래 기록과 연결.
- 계산/거래 준비 중 변경된 입력에 과거 응답을 적용하지 않는 revision 검사.
- 계획 저장·조건 복원·JSON 내보내기, 가상 회고의 원래 예상/가상 결과/차이 비교.
- API 요청 검증·Origin/Host 제한·서버 전용 키·요청 한도·민감한 요청 로그 금지.
- 독립 Docker 배포 준비. 현재 서버는 로컬 루프백만 사용.

## 아직 확인하거나 추가해야 하는 것

1. **AI 실제 연동**: `.env`에 전용 `OPENAI_API_KEY`, 사용 가능한 `OPENAI_MODEL`을 넣어야 합니다. 이번에는 키를 추가하거나 유료 모델 호출을 하지 않았습니다.
2. **사용자 지갑 왕복 검증**: TronLink 계정·필요한 USDT/TRX를 사용자가 준비한 뒤 소액 승인→예치→회수를 직접 확인·서명해야 합니다. 코드는 구현했지만 실자금 성공을 주장하지 않습니다.
3. **USDD 계약 불일치**: 공식 문서와 API/온체인의 기초자산이 일치하지 않습니다. `docs/CHAIN-INTEGRATION.md`의 근거를 확인하고 공식 정정/현재 주소를 확보하기 전 경로를 활성화하지 않습니다.
4. **실제 개인 수익 원장**: 지금은 실제 포지션·거래 결과 조회와 가상 회고입니다. 외부 앱 입출금·토큰 이전까지 반영한 실현 수익 집계는 없습니다.
5. **제출/배포**: 해커톤 영상·공개 저장소·발표자료 형식을 주최 측 별도 안내로 확인해야 합니다. 이 저장소는 로컬이며 공개 배포나 외부 저장소 생성은 하지 않았습니다.
