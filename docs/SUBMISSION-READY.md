# 제출 직전 점검 — 2026-09-29

**판정: 작동하는 해커톤 프로토타입으로 제출 자료를 만들 수 있습니다. 다만 AI의 실제 응답과 사용자 서명 실행을 아직 입증하지 못했으므로, 공식 요구를 모두 검증했다고 소개하면 안 됩니다.** 기능을 더 넓히기보다 이 두 흐름의 증거와 심사위원이 열 수 있는 제출물을 우선합니다.

이 판단은 공식 [TRON Challenge Brief, 2페이지](https://drive.google.com/file/d/1HXLhu1_vCoMD5aN3APEYEjDrh9oVCj7g/view)의 Challenge B와 현재 코드·검증 기록을 비교한 것입니다. 수상 가능성이나 주최 측의 최종 합격 판정은 추정하지 않습니다. 공식 acceptance criteria는 **5개**이며, 아래는 실행과 관리를 나누어 6행으로 검토했습니다.

## 남은 시간의 우선순위

1. **AI 실제 동작 확인.** 프로젝트 전용 `OPENAI_API_KEY`와 사용 가능한 `OPENAI_MODEL`을 서버에 설정하고 재시작합니다. 브라우저에서 완전한 요청과 누락된 요청을 각각 해석하고 원문과 구조화 결과를 확인합니다. 설정 표시만으로 성공이라고 판단하지 않습니다. 키를 문서·채팅·영상에 노출하지 않습니다.
2. **실행 증거 확보.** 사용자가 TronLink 계정·USDT·TRX와 시험 금액을 준비한 경우만 직접 승인→예치→회수를 확인·서명합니다. 원계획, 거래 ID, 확정 결과, 프로토콜 반환 코드를 남깁니다. 환경이 없으면 미검증 경계를 공개하고 모의 검사 증거를 첨부합니다. 마감 때문에 근거 없이 계약·체인·금액을 바꾸지 않습니다.
3. **열 수 있는 제출물.** 확정된 제출 폼의 요구에 맞춰 실제 저장소/실행 링크, 녹화본, 필요한 팀 정보를 채웁니다. 현재 공개 URL과 원격 저장소는 없습니다. 로컬 주소는 심사위원이 외부에서 열 수 있는 링크가 아닙니다. 배포 절차는 `DEPLOYMENT.md`, 소개문은 `SUBMISSION-TEXT.md`, 대본은 `DEMO-SCRIPT.md`를 사용합니다.
4. **핵심 장면을 제출.** `artifacts/submission/treasury-demo.mp4`에 실제 앱의 데모 입력·비교·추가 지출·가상 회고·단기 보유 장면을 담은 짧은 무음 녹화본을 준비합니다. AI 응답·실거래·실시간 PSM 성공을 담은 영상은 아닙니다. 공식 요구 길이와 형식이 확인되면 `DEMO-SCRIPT.md`를 바탕으로 설명을 추가합니다.

추가 USDD 자금 실행, SUN/sTRX, 브리지, 자동 리밸런싱, 전체 개인 수익 원장은 이번 마감 전 우선 작업에서 제외해도 됩니다. 특히 회고의 가상 시연 허용은 **전체 실행 요건 면제**라는 뜻이 아닙니다.

## 재현과 최종 검증

```sh
npm ci
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run smoke
npm start
```

기본 로컬 URL은 http://127.0.0.1:4187 입니다. 실제 키·지갑 없이 데모를 실행할 수 있습니다. 테스트의 지갑은 모의 지갑이며 실제 자금을 움직이지 않습니다. 최종 테스트 개수·커밋·공식 API 조회 시각은 변경 완료 후 갱신되는 [RESUME.md](RESUME.md)를 기준으로 기재합니다.
