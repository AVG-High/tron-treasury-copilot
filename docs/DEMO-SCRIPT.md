# 3분 시연 대본

이 길이는 발표 준비용 제안이며 공식 영상 길이가 확인됐다는 뜻은 아닙니다. 실제 제출 형식은 [제출 체크리스트](SUBMISSION-CHECKLIST.md)에서 확인합니다. 시연은 기본 데모 모드에서 시작합니다. 화면 수치를 현재 시장 APY나 실제 수익으로 소개하지 않습니다.

## 촬영 전 입력

기본 시나리오: 총자금 10,000 USDT, 7일 뒤 3,000 지출, 30일 뒤 1,000 지출, 비상금 500, 잔여 자금 운용 30일. UI의 비용·노출 기본값을 유지합니다. 계산 후 `4,500 예약`과 `5,500 운용 검토 가능`을 확인하고 계획을 저장합니다. 운용 가능 금액에는 비용 예약도 포함되므로 실제 투자 원금은 그보다 작습니다.

두 번째 소액 시나리오를 별도 탭에 준비합니다: 총자금 2,000, 지출 항목 없음, 비상금 0, 운용 7일, USDD 상한 0%, 프로토콜 상한 100%, JustLend USDT 왕복 비용 4. 데모 데이터에서 보유안만 남는 것을 검증했습니다. 현재 실시간 APY로 같은 결과가 나온다고 단정하지 않습니다.

AI 키가 없다면 수동 입력 상태를 그대로 보여줍니다. 본인 자금이 들어 있는 브라우저 기록 대신 이 프로젝트의 별도 데모 브라우저 프로필을 사용합니다. 실제 지갑이 준비되지 않은 경우 지갑 부분은 구현 경계 설명으로 대체하고 서명 성공 화면을 꾸미지 않습니다.

## 실행 시연을 별도로 준비할 경우

3분 영상 중 지갑 서명과 체인 확정을 기다리려고 급하게 금액을 바꾸지 않습니다. 별도 사용자 승인 소액, 정확한 토큰/네트워크, 필요한 TRX 자원을 정한 뒤 승인→예치→회수를 순서대로 검증합니다. 실제 거래를 했다면 해당 거래 ID와 확정 상태를 근거로 기록하고, 그렇지 않으면 “모의 브라우저 테스트”와 “미검증 실거래”로 구분합니다. 가짜 확정 영수증이나 실제처럼 보이는 테스트 지갑 잔고를 영상에 섞지 않습니다.

서명 수량은 무제한이 아니며 기존 nonzero allowance가 있으면 0 초기화가 추가로 필요할 수 있습니다. 회수 준비에서도 현재 유동성·포지션·차입 여부를 다시 확인하므로 미리 저장한 견적으로 성공을 보장하지 않습니다.

## 질문에 대한 짧은 답변

- **AI가 알아서 매매하나요?** “조건을 구조화하고 설명하는 데 사용합니다. 수량·예약금·노출 계산은 결정론적이며 거래마다 사용자가 지갑에서 서명합니다.”
- **왜 USDD를 바로 투자하지 않나요?** “동일한 심볼만 보고 자산을 연결하지 않습니다. 공식 주소·기초자산·양방향 전환·회수 유동성의 증거가 충족되어야 활성화합니다.”
- **표시된 순수익은 보장되나요?** “현재 수익률과 비용 가정에 따른 예상입니다. 금리·보상·수수료·회수 유동성이 바뀔 수 있어 별도로 보여줍니다.”
- **얼마를 실제로 벌었나요?** “가상 회고와 실제 관측을 분리합니다. 외부 앱의 입출금·토큰 이전을 포함한 전체 원장이 없으면 개인 실현 수익으로 주장하지 않습니다.”
- **심사 요구를 모두 충족했나요?** “구현과 미검증 항목을 제출 체크리스트에 공개했습니다. 특히 USDD 연동 인정 범위와 실제 실행 증거는 제출 전에 확인해야 합니다.”

추가 시연 시간이 있다면 실시간 계획을 확인한 후 `포지션·회고 → 지금 관측`을 보여줍니다. 자동 조회는 브라우저가 보이는 동안만 작동하며, `남은 기간 조건 검토`는 재계산할 입력을 여는 기능이라고 설명합니다. 실제 시장이 변하지 않았는데 변화한 것처럼 연출하지 않습니다. 관측 평가액 차이와 실제 순수익도 구분합니다.
