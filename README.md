# TRON Treasury Copilot

**돈이 필요할 때, 준비된 자금.** 예정 지출과 비상금을 먼저 확보하고, 남는 USDT의 운용안을 비용·유동성·노출 한도와 함께 비교합니다. GWDC 2026 Korea / TRON Challenge B를 위한 독립 프로젝트입니다.

## 실행

Node.js 22.12 이상이 필요합니다. 개발에 사용한 버전은 Node 24입니다.

```sh
npm ci
npm run dev
```

- 화면: http://127.0.0.1:4177
- API: http://127.0.0.1:4187
- 기본은 **데모 모드**, 실제 지갑 없이 사용 가능합니다.
- 실시간 스위치는 JustLend·USDD 공식 API를 조회합니다. 장애를 데모 수치로 대체하지 않습니다.

프로덕션 빌드를 로컬에서 확인하려면 `npm run build` 후 `npm start`를 실행하고 http://127.0.0.1:4187 을 엽니다.

## 구현된 흐름

1. 금액·예정 지출·비상금·남는 자금의 운용 기간·노출 상한을 입력합니다.
2. 조건을 확인하면 지출 예약금과 비용을 확보한 상태에서 보유 기준안과 최대 2개의 양의 순수익 운용안을 비교합니다. 조건상 불가능하면 대안을 꾸며내지 않습니다.
3. 기본 이자와 인센티브를 분리하고, 왕복 비용·손익분기·유동성·제외 이유를 표시합니다.
4. 지출일 변경·추가 지출·운용 기간 단축 시나리오를 계산합니다. 이미 예약한 지출이 앞당겨져도 투자액을 불필요하게 바꾸지 않습니다.
5. 계획과 가정을 브라우저에 저장·복원·JSON 내보내기 합니다.
6. 포지션·회고 화면은 실제 지갑 조회와 명시적인 가상 회고를 구분합니다. 가상 회고는 금리/비용 변화에 따른 예상 대비 차이를 보여주며 실제 실현 수익으로 표시하지 않습니다.
7. 실시간 모드에서 TronLink를 연결하면 USDT 정확한 승인·0 초기화·JustLend 예치·회수를 준비할 수 있습니다. 각 거래는 실제 비용 견적과 전문을 확인하고 사용자 지갑에서 서명합니다.
8. 서명 후 거래 ID를 먼저 보존하고 확정 영수증·프로토콜 반환 코드를 확인합니다. 미확정 거래는 자동 재전송하지 않습니다.
9. 확인한 실시간 계획의 금리·유동성·예약금·지출 도래를 1/5/15분 간격으로 관측할 수 있습니다. 기본 OFF이며 브라우저가 보이는 동안만 동작합니다. 3회 연속 실패 시 중지합니다.
10. 남은 기간의 조건을 다시 검토하고 계산할 수 있습니다. 날짜가 지난 지출도 예약을 유지하며, 포지션 관측 기록의 변화는 실제 순수익과 구분합니다. 자세한 동작은 [MONITORING.md](docs/MONITORING.md).

## AI 설정 (선택)

`.env.example`을 `.env`로 복사하고 **이 프로젝트 전용** 설정을 넣습니다. 다른 프로젝트의 키를 자동으로 읽지 않습니다.

- `OPENAI_API_KEY`, `OPENAI_MODEL`: 모두 설정한 경우 Responses API의 구조화 출력으로 자연어 조건을 해석합니다. 입력은 사용자에게 다시 표시하고 사용자가 확인해야 계산합니다. 키·모델 미설정 시 수동 입력 모드이며 AI가 해석했다고 표시하지 않습니다.
- `TRONGRID_API_KEY`: 공개 RPC 호출 한도를 완화하는 선택 설정입니다. 없으면 제한적인 읽기 재시도 후 실패를 명시합니다.
- 개인키·시드·서명 비밀은 서버 설정에 넣지 않습니다.

자연어 입력은 ‘조건 해석’을 눌렀을 때만 OpenAI로 전송됩니다. 서버 키는 브라우저 번들에 포함되지 않습니다.

## 중요한 현재 경계

- **USDD PSM→JustLend 경로는 비활성화**되어 있습니다. USDD 토큰 주소는 최신 공식 배포 문서·JustLend 기초자산·PSM 읽기가 일치하여 정정했습니다. 다만 양방향 한도와 전체 전환·회수 실행 경로는 미구현이라 투자 후보로 추천하지 않습니다. 재현 근거는 [USDD-VERIFICATION.md](docs/USDD-VERIFICATION.md).
- 실제 예치/회수 코드는 구현·모의 검증됐지만 사용자 지갑의 **실자금 거래는 수행하지 않았습니다**. 차입이 있는 계정의 회수는 지원하지 않습니다.
- 계획의 왕복 비용은 사용자 가정입니다. 서명 전 실제 거래 비용은 별도로 추정하고, 미래 회수 비용을 확정 비용처럼 보장하지 않습니다.
- 개인 실제 수익의 전체 입출금 원장을 복원하는 기능은 없습니다. 주기적 포지션 관측·기록·평가액 변화·거래 비용 조회와 가상 회고가 현재 범위입니다. jToken 수량이 같아도 중간 입출금이 없었다고 추정하지 않습니다.
- USDD·SUN·sTRX 실행, 자동 자금 운용, 브리지, 자체 Vault, 다중 사용자 인증은 포함하지 않습니다.
- 연결 지갑은 토큰 가격·체인·계약·코드 지문이 검증되는 TRON Mainnet에 한정합니다. 새 네트워크/주소를 임의 폴백하지 않습니다.

## 금융 계산

`총자금 = 예정 지출 + 비상금 + 추가 보유 + 투자 원금 + 왕복 비용 예약`

기본 APY는 `원금 × ((1 + APY)^(일수/365) − 1)`로 기간 환산합니다. 인센티브는 기본 제외이며, 선택 시 연환산 보상률의 단리 참고치로 별도 계산합니다. USDD 비교는 1:1 가격 시나리오이며 디페그 보장이 아닙니다. 고정 비용은 사용한 전략마다 한 번 계산하고, 두 JustLend 상품의 노출 상한은 합산합니다. 후보 탐색 범위가 제한된 비교 엔진이며 전역 최적화를 주장하지 않습니다.

## 검증

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run smoke
```

테스트에는 실제 거래·실제 OpenAI 유료 호출이 없습니다. 브라우저 검사는 개인 Chrome 프로필과 분리된 테스트 브라우저를 사용합니다. 검증 결과와 재개 지점은 [RESUME.md](docs/RESUME.md).

## 구조

| 경로         | 역할                                                          |
| ------------ | ------------------------------------------------------------- |
| `src/domain` | 입력 스키마, 정확한 금융 계산, 명시적인 데모/가상 회고        |
| `src/chain`  | 공식 데이터, 고정 계약·코드 검증, 지갑 읽기, 미서명 거래 준비 |
| `src/server` | API, 요청 검증·출처 제한, AI 조건 추출                        |
| `src/client` | 한국어 UI, 사용자 지갑 서명, 브라우저 기록                    |
| `tests`      | 계산·API·거래 경계·브라우저 검증                              |
| `docs`       | 근거, 해커톤 요건, 재개 기록, 화면                            |

## 배포 준비

Dockerfile과 Railway 설정, GitHub Actions 검증을 준비했습니다. [배포 실행서](docs/DEPLOYMENT.md)에 환경 변수·독립 서비스 설정·상태 확인을 정리했습니다. [시연 대본](docs/DEMO-SCRIPT.md)과 [제출 체크리스트](docs/SUBMISSION-CHECKLIST.md)도 포함합니다. 이 작업에서는 외부 저장소 게시나 배포를 하지 않았고 기존 Railway 서비스·DB·환경 변수를 변경하지 않았습니다.
